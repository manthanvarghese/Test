# Wada colors

Reusable color knowledge from Sanzo Wada's *A Dictionary of Color Combinations*
(Haishoku Soukan, 1933-34): 157 named colors, 348 combinations of 2-4 colors.

- `colors.json` - each color has name, hex, rgb, cmyk and the combination numbers it appears in.
- `wada.py` - CLI lookup (`combo`, `random`, `with`); no dependencies.
- Source: https://github.com/dblodorn/sanzo-wada (MIT, see `LICENSE-sanzo-wada`).

A combination is the set of colors sharing the same number in `combinations`.
